Language

What is it for?

The system can be used in Spanish or English, and the administrator can create other languages by translating the texts.

Steps

  1. To change the language, go to the Language menu and choose one. Open screens are translated automatically.
  2. To create a new language, go to New Language, type the name and press Create.
  3. The grid shows every original text. Fill in the Translation column in every row.
  4. Press Save. The new language appears in the Language menu.
  5. The help is written in Spanish and English. With another language it is shown in Spanish.

Common errors

  • If you see Complete Language: the language name is missing before pressing Create.
  • If you see Enter Translation for: ...: a row was left without translation, fill it in before saving.
