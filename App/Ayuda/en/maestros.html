Condominium maintenance

What is it for?

Here the administrator loads and edits condominiums, units, owners and suppliers. Nothing is deleted: removals are logical and can be reactivated.

Steps

  1. Go to Condominium maintenance and choose the tab (Condominiums, Units, Owners or Suppliers).
  2. To add one press New, fill in the data and press Save.
  3. To edit, choose the row in the grid, change the data and press Save.
  4. To remove one use Deactivate (Disable for suppliers). To activate it again use Reactivate or Enable.
  5. In Units choose the condominium first. With a unit selected, Ver historial opens the change log.
  6. In Owners choose the owner and the unit and press Assign as owner. To remove it there is Remove owner.

Common errors

  • If you see Debe completar nombre y direccion: the condominium name and address are missing.
  • If you see La cantidad de unidades debe ser mayor a cero / Debe seleccionar un gestor: enter the number of units and choose the manager.
  • If you see No se puede inactivar un consorcio con unidades funcionales activas: deactivate its units first.
  • If you see Debe completar numero y tipo / El coeficiente debe ser mayor a cero: check the unit data.
  • If you see Ya existe una unidad funcional con ese numero en el consorcio: the number cannot be repeated in the condominium.
  • If you see El consorcio ... ya tiene registradas sus N unidades funcionales: all the units of the condominium are already loaded. If needed, increase its number of units.
  • If you see No se puede inactivar una unidad funcional con expensas pendientes o vencidas: those fees have to be paid or cancelled first.
  • If you see Debe completar nombre y apellido / El DNI debe tener 7 u 8 digitos: check the owner data.
  • If you see La unidad funcional ya tiene un propietario asignado; quítelo antes de asignar uno nuevo: use Remove owner and then assign the new one.
  • If you see No se puede quitar el propietario de una unidad funcional con expensas pendientes o vencidas: those fees have to be paid or cancelled first.
  • If you see Debe completar el nombre / Ya existe un proveedor con ese nombre: type a supplier name that is not loaded yet.
