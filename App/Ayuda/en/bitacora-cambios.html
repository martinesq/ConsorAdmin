Unit change log

What is it for?

Shows every version a unit had (creation, changes, deactivations, reactivations and restorations) and lets you take the unit back to a previous version. This screen is only in Spanish.

Steps

  1. In Condominium maintenance > Units choose a unit and press Ver historial.
  2. The history is on the left and the current unit is on the right.
  3. To filter choose Id or Número, type the value, tick Fecha desde and/or Fecha hasta for a date range and press Aplicar.
  4. Limpiar goes back to the filter the screen was opened with.
  5. To restore, choose a version, press Activar and confirm. A new version with operation Restauracion is added.

Common errors

  • If you see La fecha desde no puede ser posterior a la fecha hasta: the From date is after the To date, fix the range.
  • If you see El Id debe ser un numero / No se encontro la unidad funcional ...: the unit has to belong to the same condominium.
  • If you see Seleccione una version del historial: choose a row before pressing Activar.
  • If you see La version elegida es igual a la vigente: there is nothing to restore.
  • If you see No se puede restaurar una version inactiva: la unidad funcional tiene expensas pendientes o vencidas: those fees have to be paid or cancelled first.
  • If you see Ya existe una unidad funcional con ese numero en el consorcio: another unit is using that number.
