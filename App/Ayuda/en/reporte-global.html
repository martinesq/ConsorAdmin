Global report

What is it for?

Shows one row per condominium with billed, collected, overdue debt, collection rate, costs, pending services, payments and balance. They are sorted from best to worst collection. The administrator sees all condominiums and the manager only their own.

Steps

  1. Go to Global report.
  2. Choose the From and To dates.
  3. Press Generate. The totals are below.
  4. Press Export PDF to save it. If the dates change it has to be generated again.

Common errors

  • If you see La fecha desde no puede ser posterior a la fecha hasta: the From date is after the To date, fix the dates.
  • If you see There are no active consortiums for the selected period: the user has no condominiums to show.
  • If you see The file could not be saved. Check that it is not open in another program: close the PDF in the other program or save it with another name.
