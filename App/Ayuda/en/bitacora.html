Audit Log

What is it for?

Shows what the users did in the system (logins, creations, changes, etc.). It can be filtered and exported to CSV.

Steps

  1. Go to Audit Log.
  2. Choose the user or leave (All).
  3. For a date range, tick Filter by date and choose From and To.
  4. Optionally type part of the activity.
  5. Press Search.
  6. Press Export CSV to save what is in the grid.

Common errors

  • If you see Error exporting: check that the file is not open in another program (for example Excel).
