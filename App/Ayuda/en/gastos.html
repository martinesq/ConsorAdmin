Costs

What is it for?

The condominium costs of each period are loaded here. Later the fee settlement is built with these costs.

Steps

  1. Go to Fee Settlement > Costs.
  2. Choose the condominium. The grid shows the costs already loaded.
  3. Fill in description, category, period and amount.
  4. Press Save.

Common errors

  • If you see You have no assigned consortiums: the user does not manage any condominium with active units.
  • If you see Debe completar descripcion y rubro: description and category are required.
  • If you see El monto debe ser mayor a cero: enter a valid amount.
  • If you see El periodo MM/AAAA ya tiene una liquidacion de expensas generada; no se pueden cargar mas gastos para ese periodo: that period is already settled, load the cost in the next period.
