Integrity resolution

What is it for?

When logging in the system checks the check digits. If some data was changed outside the system, this screen opens for the administrator with the failing tables and rows. Other users cannot log in until it is solved.

Steps

  1. Check in the grid which tables, rows and fields fail.
  2. Restore from backup: choose a .bak and confirm. The database goes back to that backup.
  3. Recalculate check digits: the current data is taken as correct and calculated again.
  4. Cancel: nothing is fixed and the session is closed.

Common errors

  • If you see The data integrity check is still failing. Review the details and choose another action.: the chosen backup also has problems, try another one or recalculate.
  • If you see The restored backup does not contain the current administrator. You must log in again.: log in again with a user that exists in that backup.
  • If you see Error restoring database / Error recalculating the check digits: try again and, if it continues, check the database connection.
