Submit service request

What is it for?

It is the first step of a service: what has to be done and where is registered. The request becomes Pendiente de asignacion.

Steps

  1. Go to Service Management > Submit service request.
  2. Choose the condominium.
  3. Fill in category and description.
  4. In location choose Common area or Unit (in that case choose the unit).
  5. Press Confirm request. The request number appears below.

Common errors

  • The Confirm request button is disabled: category or description is missing.
  • If you see Debe seleccionar la unidad funcional: Unit was chosen but no unit was selected.
