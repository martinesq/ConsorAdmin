Backup / Restore

What is it for?

Used to make a security copy of the database in a .bak file and to take the database back to how it was in a backup.

Steps

  1. Go to Database > Backup / Restore.
  2. To make a copy press Make Backup and choose where to save the .bak file.
  3. To restore press Restore, choose the .bak file and confirm. The current data is lost.

Common errors

  • If you see Error performing backup: check that the folder exists. The file is written by SQL Server, so the folder has to be accessible for the service.
  • If you see This action replaces the current data. Do you want to continue?: press Yes only if you want to go back to that backup.
  • If you see Error restoring database: check that the file is a backup of this database and that there are no other open connections.
