Log in

What is it for?

Used to enter the system with the username and password. Once inside, the menu only shows the options the user is allowed to use.

Steps

  1. Go to Session > Log In.
  2. Type the username and the password.
  3. Press Enter. If the data is right a welcome message appears.
  4. To leave, go to Session > Log Out.

Common errors

  • If you see Incorrect User: the user does not exist, check how it was written.
  • If you see Incorrect Password: the password does not match. After 4 failed attempts the next one blocks the user.
  • If you see Blocked User: ask an administrator to unblock it from Users.
  • If you see User Deactivated: the user was deactivated, talk to an administrator.
  • If you see The system is not available right now. Contact an Administrator.: the system found an integrity problem in the data. Only the administrator can log in and fix it.
