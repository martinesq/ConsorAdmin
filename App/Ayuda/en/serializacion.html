Serialize / deserialize expenses

What is it for?

Saves the pending or overdue fees of a condominium in an XML file and opens an XML to see what it has. What is read is not saved in the database.

Steps

  1. Go to Serialize/Deserialize expenses.
  2. Choose the condominium. The administrator sees all of them and the manager only their own.
  3. Serialize: choose where to save the XML.
  4. Deserialize: choose an XML. The fees appear in the grid.

Common errors

  • If you see Could not serialize: ...: check that the folder exists and can be written.
  • If you see The file does not exist: choose a file that exists.
  • If you see The file does not have a valid expenses format: the XML was not generated by the system.
  • If you see Could not read the file: ...: check that the file is not open in another program.
