Users

What is it for?

Here the administrator creates users, edits their data, blocks or unblocks them and assigns permissions (families or single patents).

Steps

  1. Go to Users.
  2. To create one press New User, type the username and the password and press Ok.
  3. To edit, choose the user in the grid, press Edit, change the data and press Ok.
  4. With the user selected you can Block, Unlock or Reactivate it.
  5. For permissions, choose a family or a patent and press <--Add. To remove one choose it in User Permissions and press Remove-->.
  6. Press Save so the permissions are stored.

Common errors

  • If you see Ya tiene este permiso: the user already has that patent, directly or inside one of their families.
  • If you see Ya tiene una patente de esta familia, eliminelo para poder agregar la familia: remove the single patent first and then add the family.
  • A user cannot log in because it is blocked: choose it and press Unlock.
