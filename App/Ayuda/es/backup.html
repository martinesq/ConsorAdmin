Backup / Restaurar

¿Para qué sirve?

Sirve para hacer una copia de seguridad de la base de datos en un archivo .bak y para volver la base a como estaba en un backup.

Pasos

  1. Ir a Base de Datos > Backup / Restaurar.
  2. Para hacer una copia apretar Hacer Backup y elegir dónde guardar el archivo .bak.
  3. Para restaurar apretar Restaurar, elegir el archivo .bak y confirmar. Ojo que se pierden los datos actuales.

Errores comunes

  • Si aparece Error al realizar el backup: revisar que la carpeta exista. El archivo lo escribe SQL Server, así que la carpeta tiene que ser accesible para el servicio.
  • Si aparece Esta accion reemplaza los datos actuales. Desea continuar?: apretar Sí solamente si se quiere volver a ese backup.
  • Si aparece Error al restaurar la base de datos: revisar que el archivo sea un backup de esta base y que no haya otras conexiones abiertas.
