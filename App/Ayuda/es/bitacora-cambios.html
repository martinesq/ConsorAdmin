Bitácora de cambios

¿Para qué sirve?

Muestra todas las versiones que tuvo una unidad funcional (alta, modificaciones, bajas, reactivaciones y restauraciones) y deja volver la unidad a una versión anterior.

Pasos

  1. En Mantenimiento de consorcios > Unidades Funcionales elegir una unidad y apretar Ver historial.
  2. A la izquierda está el historial y a la derecha cómo está la unidad ahora.
  3. Para filtrar elegir Id o Número, escribir el valor, tildar Fecha desde y/o Fecha hasta si se quiere un rango y apretar Aplicar.
  4. Limpiar vuelve al filtro con el que se abrió la pantalla.
  5. Para restaurar, elegir una versión, apretar Activar y confirmar. Se agrega una versión nueva con operación Restauracion.

Errores comunes

  • Si aparece La fecha desde no puede ser posterior a la fecha hasta: corregir el rango de fechas.
  • Si aparece El Id debe ser un numero / No se encontro la unidad funcional ...: la unidad tiene que ser del mismo consorcio.
  • Si aparece Seleccione una version del historial: elegir una fila antes de apretar Activar.
  • Si aparece La version elegida es igual a la vigente: no hay nada para restaurar.
  • Si aparece No se puede restaurar una version inactiva: la unidad funcional tiene expensas pendientes o vencidas: primero tienen que pagarse o anularse esas expensas.
  • Si aparece Ya existe una unidad funcional con ese numero en el consorcio: otra unidad está usando ese número.
