Usuarios

¿Para qué sirve?

Acá el administrador crea los usuarios, les cambia los datos, los bloquea o desbloquea y les asigna permisos (familias o patentes sueltas).

Pasos

  1. Ir a Usuarios.
  2. Para crear uno apretar Nuevo Usuario, escribir el nombre de usuario y la contraseña y apretar Aceptar.
  3. Para modificar, elegir el usuario en la grilla, apretar Editar Datos, cambiar los datos y apretar Aceptar.
  4. Con el usuario elegido se puede Bloquear, Desbloquear o Reactivar.
  5. Para los permisos, elegir una familia o una patente y apretar <--Agregar. Para sacar uno elegirlo en Permisos Usuario y apretar Quitar-->.
  6. Apretar Guardar para que queden grabados los permisos.

Errores comunes

  • Si aparece Ya tiene este permiso: el usuario ya tiene esa patente, directa o dentro de una de sus familias.
  • Si aparece Ya tiene una patente de esta familia, eliminelo para poder agregar la familia: primero hay que quitarle la patente suelta y después agregar la familia.
  • Un usuario no puede entrar porque está bloqueado: elegirlo y apretar Desbloquear.
