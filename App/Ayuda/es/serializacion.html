Serializar / deserializar expensas

¿Para qué sirve?

Guarda en un archivo XML las expensas pendientes o vencidas de un consorcio y permite abrir un XML para ver lo que tiene. Lo que se lee no se guarda en la base de datos.

Pasos

  1. Ir a Serializar/Deserializar expensas.
  2. Elegir el consorcio. El administrador ve todos y el gestor solamente los suyos.
  3. Serializar: elegir dónde guardar el XML.
  4. Deserializar: elegir un XML. Las expensas aparecen en la grilla.

Errores comunes

  • Si aparece No se pudo serializar: ...: revisar que la carpeta exista y que se pueda escribir.
  • Si aparece El archivo no existe: elegir un archivo que exista.
  • Si aparece El archivo no tiene un formato de expensas valido: el XML no es uno generado por el sistema.
  • Si aparece No se pudo leer el archivo: ...: revisar que el archivo no esté abierto en otro programa.
