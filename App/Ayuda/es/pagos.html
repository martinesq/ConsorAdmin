Cobrar expensa

¿Para qué sirve?

Se registra el pago total o parcial de una expensa de una unidad y se genera el comprobante.

Pasos

  1. Ir a Liquidación de Expensas > Cobrar expensa.
  2. Elegir el consorcio y la unidad funcional. Aparecen sus expensas pendientes.
  3. Elegir la expensa. Arriba se ve el monto, lo pagado, el saldo, el vencimiento y el estado.
  4. Poner el monto, elegir el medio de pago (Efectivo, Transferencia, Débito o Cheque) y apretar Cobrar expensa.
  5. Si se paga todo la expensa queda Pagada y se muestra el comprobante. Si se paga una parte se muestra lo que falta.

Errores comunes

  • Si aparece La unidad no tiene expensas pendientes de pago: la unidad está al día.
  • Si aparece El monto ingresado supera la deuda. ¿Confirma el excedente ... como saldo a favor?: apretar Sí para registrarlo igual o No para corregir el monto.
