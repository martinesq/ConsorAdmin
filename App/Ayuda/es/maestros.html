Mantenimiento de consorcios

¿Para qué sirve?

Acá el administrador carga y modifica los consorcios, las unidades funcionales, los consorcistas y los proveedores. Nada se borra: las bajas son lógicas y se pueden reactivar.

Pasos

  1. Ir a Mantenimiento de consorcios y elegir la pestaña (Consorcios, Unidades Funcionales, Consorcistas o Proveedores).
  2. Para agregar uno apretar Nuevo, completar los datos y apretar Guardar.
  3. Para modificar, elegir la fila de la grilla, cambiar los datos y apretar Guardar.
  4. Para dar de baja usar Inactivar (en proveedores Inhabilitar). Para volver a activarlo usar Reactivar o Habilitar.
  5. En Unidades Funcionales primero se elige el consorcio. Con una unidad elegida, Ver historial abre la bitácora de cambios.
  6. En Consorcistas se elige el consorcista y la unidad y se aprieta Asignar como propietario. Para sacarlo está Quitar propietario.

Errores comunes

  • Si aparece Debe completar nombre y direccion: faltan datos del consorcio.
  • Si aparece La cantidad de unidades debe ser mayor a cero / Debe seleccionar un gestor: completar la cantidad de unidades y elegir el gestor.
  • Si aparece No se puede inactivar un consorcio con unidades funcionales activas: primero hay que inactivar sus unidades.
  • Si aparece Debe completar numero y tipo / El coeficiente debe ser mayor a cero: revisar los datos de la unidad.
  • Si aparece Ya existe una unidad funcional con ese numero en el consorcio: el número no se puede repetir dentro del consorcio.
  • Si aparece El consorcio ... ya tiene registradas sus N unidades funcionales: ya están cargadas todas las unidades del consorcio. Si hace falta, aumentar la cantidad de unidades del consorcio.
  • Si aparece No se puede inactivar una unidad funcional con expensas pendientes o vencidas: primero tienen que pagarse o anularse esas expensas.
  • Si aparece Debe completar nombre y apellido / El DNI debe tener 7 u 8 digitos: revisar los datos del consorcista.
  • Si aparece La unidad funcional ya tiene un propietario asignado; quítelo antes de asignar uno nuevo: usar Quitar propietario y después asignar el nuevo.
  • Si aparece No se puede quitar el propietario de una unidad funcional con expensas pendientes o vencidas: primero tienen que pagarse o anularse esas expensas.
  • Si aparece Debe completar el nombre / Ya existe un proveedor con ese nombre: escribir un nombre de proveedor que no esté cargado.
