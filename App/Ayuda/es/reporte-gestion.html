Reporte de gestión

¿Para qué sirve?

Junta en una pantalla la composición de una expensa, la morosidad, el estado del fondo y el estado de cuenta de un consorcio. Se puede exportar a PDF.

Pasos

  1. Ir a Liquidación de Expensas > Reporte de gestión.
  2. Elegir el consorcio y en cada pestaña el filtro (unidad, período o unidad / consorcio completo).
  3. Apretar Generar.
  4. En Composición de expensa elegir una expensa para ver sus gastos. En Estadísticas de morosidad elegir una unidad para ver el detalle.
  5. Apretar Exportar PDF para guardar las cuatro consultas en un archivo.

Errores comunes

  • Si aparece No tiene consorcios asignados: el usuario no gestiona ningún consorcio.
  • Si aparece El consorcio no registra unidades morosas / El período no registra pagos ni egresos / No hay movimientos registrados: no es un error, no hay datos para ese filtro.
  • Si aparece No se pudo generar el PDF, intente nuevamente: volver a exportar.
