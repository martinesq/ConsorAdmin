Iniciar sesión

¿Para qué sirve?

Sirve para entrar al sistema con el usuario y la contraseña. Una vez adentro el menú muestra solamente las opciones que el usuario tiene permitidas.

Pasos

  1. Ir a Sesión > Iniciar Sesión.
  2. Escribir el nombre de usuario y la contraseña.
  3. Apretar Ingresar. Si los datos están bien aparece el mensaje de bienvenida.
  4. Para salir, ir a Sesión > Cerrar Sesión.

Errores comunes

  • Si aparece Usuario Incorrecto: el usuario no existe, revisar cómo se escribió.
  • Si aparece Contraseña Incorrecta: la contraseña no coincide. Ojo que después de 4 intentos fallidos el siguiente bloquea al usuario.
  • Si aparece Usuario Bloqueado: hay que pedirle a un administrador que lo desbloquee desde Usuarios.
  • Si aparece Usuario Dado de Baja: el usuario fue dado de baja, hablar con un administrador.
  • Si aparece El sistema no está disponible en este momento / Contacte con un Administrador.: el sistema encontró un problema de integridad en los datos. Solamente el administrador puede entrar y resolverlo.
