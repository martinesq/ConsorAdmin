Resolución de integridad

¿Para qué sirve?

Al iniciar sesión el sistema controla los dígitos verificadores. Si algún dato se cambió por fuera del sistema, al administrador se le abre esta pantalla con las tablas y filas que fallan. Los demás usuarios no pueden entrar hasta que se resuelva.

Pasos

  1. Revisar en la grilla qué tablas, filas y campos fallan.
  2. Restaurar desde backup: elegir un .bak y confirmar. La base vuelve a ese backup.
  3. Recalcular dígitos verificadores: se toman los datos actuales como correctos y se vuelven a calcular.
  4. Cancelar: no se arregla nada y se cierra la sesión.

Errores comunes

  • Si aparece La integridad de los datos sigue fallando. Revise el detalle y elija otra acción.: el backup elegido también tiene problemas, probar con otro o recalcular.
  • Si aparece El backup restaurado no contiene al administrador actual. Debe iniciar sesión nuevamente.: volver a iniciar sesión con un usuario que exista en ese backup.
  • Si aparece Error al restaurar la base de datos / Error al recalcular los dígitos verificadores: volver a intentar y, si sigue, revisar la conexión con la base.
