Registrar egreso a proveedor

¿Para qué sirve?

Registra un pago que sale del fondo del consorcio, ya sea un servicio aprobado o una compra de insumos. El egreso queda cargado como gasto para la próxima liquidación.

Pasos

  1. Ir a Liquidación de Expensas > Registrar egreso a proveedor.
  2. Elegir el consorcio. Se ve el saldo disponible y los servicios aprobados que falta pagar.
  3. Para pagar un servicio elegirlo en la grilla. Para una compra de insumo no elegir ningún servicio y completar concepto y monto.
  4. Apretar Confirmar egreso.

Errores comunes

  • Si aparece El consorcio no tiene servicios aprobados pendientes de pago: solamente se puede cargar una compra de insumo.
  • Si aparece saldo insuficiente para este egreso: el monto es mayor al saldo disponible, el botón no se habilita hasta corregirlo.
  • Si aparece Saldo insuficiente: el saldo cambió antes de confirmar, revisar el saldo disponible.
  • El botón Confirmar egreso está deshabilitado: falta elegir un servicio o completar concepto y monto.
