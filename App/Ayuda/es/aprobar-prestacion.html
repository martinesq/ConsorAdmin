Aprobar prestación

¿Para qué sirve?

Se revisa el trabajo cargado y se aprueba o se rechaza. Si se aprueba queda Aprobado y después se paga desde Registrar egreso a proveedor.

Pasos

  1. Ir a Gestión de Servicios > Aprobar prestación.
  2. Elegir el consorcio y la prestación. A la derecha se ve el detalle.
  3. Para aprobar apretar Aprobar prestación.
  4. Para rechazar escribir el motivo y apretar Rechazar prestación. Queda Rechazado.

Errores comunes

  • Si aparece No hay prestaciones pendientes de aprobacion: no hay trabajos para revisar en ese consorcio.
  • Si aparece Debe indicar un motivo para rechazar: escribir el motivo antes de rechazar.
